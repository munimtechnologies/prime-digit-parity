## Background (all already graded and published in this repo / the squarefree-gap-parity repo)

For an integer sieve, take the sequence of consecutive **gaps** `g_1, g_2, ...` and the
binary stream `x_n = P_2(g_n)` = parity of the base-2 digit sum of `g_n` (the Thue–Morse
value, popcount mod 2). The exact stride identity

    P_2(g) = P_4(g) XOR P_4(floor(g/2))

splits `x` into two base-4 "stride" streams `a_n = P_4(g_n)` (even-position bits) and
`b_n = P_4(floor(g_n/2))` (odd-position bits), with `x = a XOR b`. Serial memory is
measured by the lag-k statistic `S^(k) = sum_n u_n u_{n+k}` (`u = +/-1`), graded against an
**exact marginal-preserving permutation null** (reported as `z`), the same code graded in
`prime-digit-parity` v0.14.0/v0.15.0.

Published lag-1..8 profiles at N = 1e8 (prime-digit-parity v0.15.0, squarefree-lag-period)
revealed a sharp signature on the `x_base2` stream:

- **Squarefree (A005117):** lag 2 is **uniquely quiet** — |z|: lag1=502, **lag2=7**,
  lag3=496, lag4=426, lag5=441, lag6=439, lag7=427, lag8=334. At lag 2 **both** base-4
  strides are individually very loud (|z| ≈ 1891 and 914), so the base-2 near-null is a
  **destructive XOR cancellation** that happens only at lag 2.
- **Sums of two squares (A001481):** also lag-2 unique-quiet (|z| lag2 ≈ 1.45 vs others
  21–46; quiet lag = 2).
- **Primes (A000040):** **no** lag-2 signature — the quiet lag is lag 5 (|z| ≈ 0.19), and
  lag 2 (|z| ≈ 11.4) is not uniquely quiet.

Squarefree and sums-of-two-squares are both **multiplicative** sieves; primes are too but
behave differently at this fine level.

## Open question graded here

**Lucky numbers (OEIS A000959)** are generated by a purely **positional, Josephus-style
sieve** — survivors are removed by *position*, with no multiplicative (congruence) input —
yet they have prime-like density. A prior lag-1 runs test (squarefree-gap-parity v0.3.0,
limit 1e7) found lucky base-2 gap-parity **anti-persistent** (z ≈ −17) and base-16
dominant. The lag-1..8 stride profile and the lag-2 signature have **never** been computed
for lucky.

> Does the non-multiplicative lucky sieve show the base-2 **lag-2 unique-quiet signature**
> (like the multiplicative squarefree / sums-of-two-squares) or not (like primes)?

This decides whether the lag-2 XOR cancellation is a **consequence of multiplicative
congruence structure** or **generic to any thinned integer sequence**.

## Method (fixed in advance)

- Compute all four sieves to a common **N = 20,000,000** (common N keeps the comparison
  fair; the lucky positional sieve is O(N × passes), so N is chosen for lucky tractability
  while still giving ~1.2M lucky gaps — above the prior 1e7 lucky study's power). Statistics
  code (observable,
  permutation null `null_z`, stream analysis) is reused verbatim and re-self-tested from
  the graded `squarefree_lag_period_job.py`; the lucky sieve is reused and re-self-tested
  from the graded `lucky_gap_parity.py`. Self-tests run first; the job aborts (exit≠0) on
  any failure so only self-validated numbers are emitted.
- Signature detector (scale-free, so independent of N): the `x_base2` lag-2 unique-quiet
  signature is **present** iff `argmin_{k∈1..8} |z_x(k)| == 2` **and**
  `|z_x(2)| ≤ 0.1 × median{|z_x(k)| : k≠2}`.

## Pre-registered predictions (falsifiable, graded by the job against frozen thresholds)

- **P-L-1 (replication — anti-persistence).** Lucky `x_base2` lag-1 `z ≤ −8` (base-2
  anti-persistent serial memory replicates the prior 1e7 lucky result at the new N and
  under the permutation null). *Expected to HOLD.*
- **P-L-2 (PRIMARY — the decisive test).** Lucky does **NOT** show the lag-2 unique-quiet
  signature (`signature_present(lucky) == False`); i.e. lucky patterns with **primes**, not
  with squarefree / sums-of-two-squares. *Rationale: the lag-2 XOR cancellation is
  hypothesized to arise from the base-4 residue structure of multiplicative sieves, which a
  positional sieve lacks.* If **FALSIFIED** (lucky shows the signature), the cancellation is
  generic to thinned sequences — a more surprising, equally publishable outcome.
- **P-L-3 (strides carry signal).** Each lucky base-4 stride has lag-1 `|z| ≥ 5`
  (`a_base4_even` and `b_base4_odd` both). *Expected to HOLD.*

Reported but **not graded** (internal replication at this N): squarefree and
sums-of-two-squares should show `signature_present == True`, primes `== False`, reproducing
the 1e8 pattern.

## Honest limits

Lucky at N = 2e7 yields ~1.2M gaps vs squarefree's ~12M, so lucky |z| values are a few-fold
smaller; the signature test is a **ratio** test, so it is not invalidated by the smaller N,
but a null result for P-L-2 is "no signature at this power", not a proof of its impossibility
at all N. A negative or partial result is reported as such. No money or external engagement
is attached to this; it is a pre-registered number-theory micro-result.
